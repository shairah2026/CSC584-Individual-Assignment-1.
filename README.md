# CSC584-Individual-Assignment-1.
A simple web application that collects and displays student information using HTML, Java Servlet, JSP, and CSS.  Technologies: HTML, CSS, Java, Servlet, JSP, NetBeans, GlassFish Server.  How to Run: Open the project in NetBeans, configure GlassFish Server, right-click the project, select Run, and open http://localhost:8080/PersonalProfileWebApp/.
